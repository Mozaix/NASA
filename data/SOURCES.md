# Data sources

Generated by `tools/fetch_data.py` on 2026-11-05. All data is bundled; the game never goes online.
This game is not endorsed by NASA. NASA data and imagery are credited below under NASA's media usage guidelines.

## Datasets

- NASA Solar System Treks (WMTS tiles and nomenclature): https://trek.nasa.gov/
- Planetary Fact Sheet: https://nssdc.gsfc.nasa.gov/planetary/factsheet/
- NASA Exoplanet Archive, table pscomppars (TAP): https://exoplanetarchive.ipac.caltech.edu/TAP/sync
- JPL Keplerian elements for approximate planet positions: https://ssd.jpl.nasa.gov/planets/approx_pos.html
- MOLA MEGDR elevation (PDS Geosciences Node): https://pds-geosciences.wustl.edu/missions/mgs/megdr.html
- LOLA LDEM elevation (PDS Geosciences Node): https://pds-geosciences.wustl.edu/missions/lro/lola.htm
- Deep Star Maps 2020 (NASA Scientific Visualization Studio 4851): https://svs.gsfc.nasa.gov/4851

- **Mars**: Viking MDIM2.1 colour mosaic (NASA/USGS), via NASA Solar System Treks (layer `Mars_Viking_MDIM21_ClrMosaic_global_232m`)

- **Venus**: Magellan C3-MDIR radar mosaic, tinted (NASA/JPL), via NASA Solar System Treks (layer `Venus_Magellan_C3-MDIR_Global_Mosaic_2025m`)
- **Io**: Voyager ISS + Galileo SSI colour mosaic (NASA/USGS), via NASA Solar System Treks (layer `Io_GalileoSSI_Voyager_Global_Mosaic_ClrMerge_1km`)
- **Europa**: Voyager + Galileo SSI mosaic (NASA/USGS), via NASA Solar System Treks (layer `Europa_Voyager_GalileoSSI_global_mosaic_500m`)
- **Ganymede**: Voyager + Galileo SSI colour mosaic (NASA/USGS), via NASA Solar System Treks (layer `Ganymede_Voyager_GalileoSSI_Global_ClrMosaic_1435m`)
- **Callisto**: Voyager + Galileo SSI mosaic (NASA/USGS), via NASA Solar System Treks (layer `Callisto_Voyager_GalileoSSI_global_mosaic_1km`)
- **Titan**: Cassini ISS global mosaic PIA19658, tinted (NASA/JPL/SSI), via NASA Solar System Treks (layer `Titan_ISS_P19658_Mosaic_Global_4km`)
- **Enceladus**: Cassini ISS colour mosaic (NASA/JPL/SSI), via NASA Solar System Treks (layer `Enceladus_cyl_KH`)
- **Earth**: Blue Marble (NASA Scientific Visualization Studio, animation 2915) (https://svs.gsfc.nasa.gov/vis/a000000/a002900/a002915/bluemarble-2048.png)
- **Jupiter**: Cassini cylindrical map of Jupiter, PIA07782 (NASA/JPL/SSI) (https://images-assets.nasa.gov/image/PIA07782/PIA07782~orig.jpg)
- **Saturn, Uranus, Neptune, Triton**: no bundled map. Rendered with a procedural shader, labelled in-game.

## Not from NASA

- Spacecraft part costs, masses and engine figures are game values.
- Sky colours and exoplanet surfaces are artistic interpretation driven by the data above.
- Fonts: Space Grotesk and JetBrains Mono (SIL Open Font License), from Google Fonts.
- 2D Rocket Builder: part stats, prices and rewards are game values. Earth's mass, radius, air density and scale height come from the fact sheets.
- Rocket stress and strength, trick scores, rover health and the autopilot's emergency thrust are game values. The stress needle follows the shape of real dynamic pressure, but its numbers are not a real vehicle's.
- Demo quiz: questions written for this game. Results stay on the player's computer and are not a scientific study.
- Sound and music: synthesised by `tools/make_audio.py`.
- Region colour is display-graded: Viking haze patches are toned down on Mars and dark mare is exposed up on the Moon.
- Black missing-data areas in Treks mosaics are filled from surrounding pixels. Venus (radar) and Titan (near-infrared) are tinted to suggest their appearance.
